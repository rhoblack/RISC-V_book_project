## 3. 확정된 캐시 파라미터

| 파라미터 | 값 | 결정 이유 |
|---------|---|---------|
| 구조 | 직접 매핑 (Direct-Mapped) | 가장 단순, 교육 목적 최적 |
| 총 크기 | 4KB | Basys 3 BRAM 36Kb×1개로 구현 가능 |
| 블록 크기 | 32바이트 (8워드) | 공간적 지역성 활용 vs 미스 페널티 균형 |
| 엔트리 수 | 128개 | 4,096 / 32 = 128 |
| **Offset** | 5비트 [4:0] | log₂(32) = 5 |
| **Index** | 7비트 [11:5] | log₂(128) = 7 |
| **Tag** | 20비트 [31:12] | 32 - 7 - 5 = 20 |
| BRAM 사용 | 1 BRAM36 | Data: BRAM, Tag: LUTRAM, Valid: FF |

## 4. 핵심 설계 결정

### 4.1 신호 우선순위
```
flush > icache_stall > load_use_stall
```
```systemverilog
assign pc_en    = if_id_flush   ? 1'b1  :   // flush 최우선
                  icache_stall  ? 1'b0  :   // 캐시 미스 홀드
                  hdu_pc_en;                // load_use 스톨
assign if_id_en = icache_stall  ? 1'b0  :
                  hdu_if_id_en;
```

### 4.2 스톨 종류 비교 표 (교재 필수 삽입)

| 스톨 원인 | pc_en | if_id_en | id_ex_flush | 지속 사이클 |
|----------|:-----:|:--------:|:-----------:|:----------:|
| Load-Use 해저드 (Ch10) | 0 | 0 | 1 (버블) | 1사이클 |
| 분기 flush (Ch11) | 1 | flush | flush | 1~2사이클 |
| I-Cache 미스 (Ch13) | 0 | 0 | 0 (홀드) | 미스 페널티 |

### 4.3 미스 처리 FSM
- 상태: IDLE → MISS → FILL → DONE
- 미스 페널티: 5사이클 (단순화 모델: 1+4)
- `icache_stall = (state == MISS) || (state == FILL)`

### 4.4 BRAM 분리 구조 (필수 SVG)
- Tag 배열: LUTRAM (비동기 읽기) — 0사이클 Tag 비교
- Data 배열: BRAM (동기 읽기) — 파이프라인 IF 스테이지에서 자연 흡수
- Valid 배열: FF 배열 (리셋 시 all 0)

### 4.5 파이프라인 연결 전략
- rv32i_pipeline_complete 내부 최소 수정
- 새 wrapper 모듈 `ch13_pipeline_with_icache.sv`로 연결
- Ch12 코드의 교육적 완결성 보존
