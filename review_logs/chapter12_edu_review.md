## 4. 버블정렬 스캐폴딩 (12.4절) 검증

### 4.1 4단계 스캐폴딩 구현 여부

| 단계 2 | 레지스터 역할 배분 가이드, 내부 루프 핵심 부분 가이드 | ✅ x10~x19 레지스터 역할 완전 배분, 내부 루프 핵심 코드 제공 | ✅ |

| 단계 4 | FPGA 다운로드 마일스톤 | ❌ **FPGA 마일스톤 없음** — 시뮬레이션 [PASS] 메시지로 마무리 | ❌ **누락** |

### 4.2 단계 3 불일치 분석

**기획 의도**: 학생이 외부 루프를 독립적으로 작성 → 분석(Analyze) 수준 달성.
**원고 구현**: 전체 어셈블리 코드(outer_loop, inner_loop, outer_next, done 모두 포함)를 주석 형식으로 완전 제공.

이 결정의 장점: 기계어 직접 초기화 필요성 때문에 레이블↔오프셋 대응까지 모두 보여주는 것이 실용적.
이 결정의 단점: 학생이 "독립 작성"하는 경험이 없어짐. LO-4의 분석 수준 달성이 어려워짐.

**권고(Major)**: 단계 3 전체 코드 공개 전에 "먼저 직접 작성해 보십시오" 유도 박스를 삽입하고, 완성 코드를 펼침 가능한 형태(또는 전체 소스 코드 섹션으로만 위치)로 배치하여 학생이 먼저 시도하는 경험을 보장할 것. 현재 구조는 스캐폴딩이라기보다 "완전 제공"에 가깝습니다.

### 4.3 단계 4 (FPGA 마일스톤) 누락 분석

기획에서 Part 4 마일스톤으로 "버블정렬 FPGA 실행"을 명시하였으나, 원고에서는 시뮬레이션 [PASS]로 마무리됩니다. FPGA 관련 내용이 전혀 등장하지 않습니다.

**누락 정도**: Critical이 아닌 Major — 이유는:
1. 시뮬레이션 [PASS] 자체가 감정적 클라이맥스로 충분히 설계되어 있음
2. Basys 3 XDC 제약, ILA 설정 가이드 제공은 Ch12 범위를 벗어날 수 있음
3. 그러나 기획에서 "Part 4 마일스톤: 버블정렬 FPGA 실행"으로 명시된 중요 항목임

**권고(Major)**: 12.4절 또는 12.6절에 FPGA 도전 과제를 선택(optional) 형태로 추가하거나, 12.6절 요약에서 "FPGA 합성 및 다운로드는 부록 A를 참조"와 같이 경로를 안내할 것.

## 5. 12.5절 소크라테스식 접근 검증

### 5.1 4단계 구현 여부

기획에서는 "예측 유도 → 개념 복습(CPI 상대 표) → 데이터 공개(실측치) → 심층 분석(역발상)"의 4단계를 설계하였습니다. 원고 구현은 3단계로 축약되었습니다:

| 기획 단계 | 기획 내용 | 원고 구현 | 판정 |
|---------|---------|---------|------|
| 1단계 | 예측 유도 질문 박스 | ✅ "어느 것이 가장 빠를까요? 생각해보십시오" — 절 도입부 문단 | ✅ |
| 2단계 | CPI만 수치 없이 상대 비교 표 | ✅ 1단계: CPI만 보면 어떻게 보이는가? 표 제공, "잠시 생각해보십시오" | ✅ |
| 3단계 | 실측 데이터 공개 | ✅ 2단계: Fmax/CPI/실행시간/LUT 표 + 그래프(SVG) | ✅ |
| 4단계 | 역발상 — "파이프라인이 불리한 경우" | ✅ 3단계: "파이프라인이 항상 최선인가?" 3개 시나리오 | ✅ |

**평가**: 4단계 모두 구현됨. 원고에서는 "1단계/2단계/3단계" 소제목으로 명시적 구조화. 기획보다 명확하게 단계가 표시됨. ✅

### 5.2 "왜 파이프라인인가" 스스로 발견 설계

- "CPI만 보면 단일 사이클과 파이프라인이 비슷합니다. 그런데 왜 파이프라인을 쓸까요?" → 학생이 클럭 주파수를 스스로 떠올리도록 유도. ✅
- "예측이 맞았습니까? 어디서 틀렸습니까?" → 자기 점검 내면화. ✅
- metacognition 박스에서 계산 문제로 이어짐. ✅

**소크라테스식 접근 충실도: 우수.** ✅

## 9. 기획 대비 누락/변경 사항 종합

### Critical (즉시 수정 권고)
없음.

### Major (강력 권고)

1. **LO-4 목표 수준 하향 문제**: "작성할 수 있다 (분석)"에서 "이해하고 실행 결과를 얻을 수 있다"로 변경. 분석 수준 달성이 불명확. 12.4절 단계 3에서 독립 작성 유도 박스를 삽입하거나 LO-4 표현을 "분석"에 합당하게 수정 필요.

2. **스캐폴딩 단계 3 완전 제공 문제**: 기획에서 "학생이 독립 작성"으로 설계되었으나 원고에서 전체 코드 제공. "먼저 작성해보십시오" 유도 박스 삽입 또는 완성 코드를 전체 소스 코드 섹션에만 배치할 것 권고.

3. **FPGA 마일스톤 누락**: Part 4 마일스톤으로 명시된 "버블정렬 FPGA 실행"이 없음. 선택(optional) 도전 과제 또는 부록 경로 안내로 대응할 것 권고.

### Minor (개선 제안)

4. **12.5절 LUT 수치 기획-원고 불일치**: 기획 예상치(~3,000/~2,800/~4,200)와 원고 수치(~1,500/~1,200/~2,200)의 차이를 각주 또는 aside 박스에서 명시적으로 설명하면 신뢰도 향상. ("Basys 3 Artix-7 XC7A35T 실측치 기반" 명시)

5. **기획 문제 4-2 (CPI 계산) 누락**: 성능 분석 계산 능력을 명시적으로 평가하는 문제가 소실됨. metacognition 박스로 부분 대체되었으나 형식 수준 평가 불가. 보완을 권고하나 필수는 아님.
