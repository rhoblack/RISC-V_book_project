## 8. 이슈 및 개선 제안

### 🟡 M1: 19.7절 종합 분석 심화 필요

**현상**: 19.7절이 Part 7 통합 테이블(Ch16~19 역할 요약) + 신호 흐름 1문단으로 구성. L4(분석) 목표 대비 다소 간결.

**개선안**: 다음 중 하나 추가 권장:
- **통합 블록 다이어그램 SVG** 참조: timer_irq → mip.MTIP → 인터럽트 컨트롤러 → 트랩 커밋 → 파이프라인 flush → mtvec 점프의 전체 신호 경로를 시각화
- **"만약 ~가 없다면?" 반사실적 질문**: "mepc가 없다면 핸들러 복귀 시 어디로 갈까?", "mie가 없다면 모든 인터럽트를 항상 받아야 한다" 등으로 각 컴포넌트의 필요성을 분석적으로 정리

**우선순위**: 🟡 Major — L4 달성을 위해 보강 권장

### 🟡 M2: 연습문제 채점 기준 누락

**현상**: Phase 1 기획에서 각 문제별 점수 배분(1점x3 = 3점 만점, 2점x3 = 6점 만점)을 설계했으나, 초안의 `<details>` 블록에 정답만 포함되고 채점 기준은 누락됨.

**개선안**: 각 `<details>` 블록에 채점 기준 1줄 추가. 예:
```
<p><em>채점 기준: 동기/비동기 구분(1점), MIE 제어 가능성(1점), 공통 처리 경로(1점) = 3점 만점</em></p>
```

**우선순위**: 🟡 Major — 자습 시 자가 평가에 중요

### 🟢 B1: 19.6 테스트벤치 응답 시간 미측정

**현상**: 19.6 메타인지 박스에 "인터럽트 응답 시간: 약 ___사이클"이 있으나, 테스트벤치 코드에서 실제 응답 시간을 `$display`하는 로직이 없음. 학습자가 빈칸을 채우기 어려울 수 있음.

**개선안**: 시나리오 3(Timer Interrupt)에 다음 코드 추가 권장:
```
$display("Interrupt latency: %0d cycles", cycle_count);
```
또는 본문에서 "약 4사이클"이라는 기대값을 명시적으로 안내.

**우선순위**: 🟢 Minor — 메타인지 박스 답에 "약 4사이클"로 미리 제시하면 해결 가능

### 🟢 B2: 19.1 메타인지 박스 3번째 항목 답 부재

**현상**: line 210에 "예외/인터럽트가 추가되면 플러시 범위가 어떻게 달라질까? → 19.2~19.5에서 확인"으로, 구체적 답 대신 "이후 확인"으로 유보.

**개선안**: 이 방식은 "선행 조직자(advance organizer)" 역할로 유효하지만, 학습자가 빈칸을 채울 수 없는 것은 다른 메타인지 박스와 불일치. 두 가지 선택지:
1. 현재 유지 (선행 조직자로서 유효) — 권장
2. "전체 파이프라인 플러시로 확대된다"로 답 제시

**우선순위**: 🟢 Minor — 현재 방식도 교육적으로 유효
