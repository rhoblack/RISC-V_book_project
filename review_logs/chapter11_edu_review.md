### 4.1 실습 단계 구조

### 4.2 테스트벤치 충분성 평가

**11.7절 테스트벤치 강점**:
- BNE 루프 프로그램: 데이터 해저드(RAW in loop body) + 제어 해저드(BNE taken 9회) 동시 검증 ✅
- 어셈블리 주석 + 기대값 계산 설명 ✅
- 3단계 디버깅 가이드(instructor-tip)로 실패 시 자가 진단 가능 ✅
- pass/fail 자동 출력 (`$display`) ✅

**개선 권장사항**:
- JAL/JALR 전용 테스트 시나리오가 없음 — **Minor**. JAL과 JALR을 각각 검증하는 미니 테스트 케이스(2~3행) 추가 권장. 11.7절이 BNE 중심이므로 11.6절 안에 간단한 JAL 검증 코드 스니펫 1개 추가하면 보완됨.
- Load-JALR 시나리오 테스트가 연습문제 2번에만 존재 — 본문에서도 시뮬레이션 힌트 1줄 추가 고려.

## 5. 연습문제 품질 평가

### 5.1 블룸 분류 수준 분석

| 번호 | 태그 | 내용 | 블룸 수준 |
|------|------|------|-----------|
| 1 | [기본] | 버블 삽입 수 계산 | 적용 (Apply) |
| 2 | [응용] | Load-JALR 스톨 수, hazard 조건식 작성 | 적용 + 분석 |
| 3 | [분석] | PNT vs BHT 페널티 사이클 계산 | 분석 (Analyze) |
| 4 | [설계] | flush+stall 동시 발생 테스트벤치 작성 및 검증 | 적용 + 평가 |
| 5 | [도전] | BHT 통합, pc_next MUX 수정, 성능 비교 | 평가 + 창조 |

**수준 분포**: 적용(2개), 분석(2개), 평가/창조(2개)
- 기억(Remember) 수준 문제 없음 — 기억 수준 문제가 불필요할 만큼 적용 이상 수준이 풍부
- 이해(Understand) 수준 명시 문제 없음
- 분석 이상 수준 문제 4개 — **조건(최소 3수준) 충족** ✅
- 분석/평가 수준 문제 존재 ✅

### 5.2 난이도 분포 평가

난이도 점진적 상승([기본]→[응용]→[분석]→[설계]→[도전]) 구조 명확합니다. 연습문제 4번("[설계]")은 독자에게 직접 테스트벤치를 작성하게 하므로 실제 FPGA 개발 역량을 강화하는 가장 중요한 문제입니다.

**개선 권장사항**: 연습문제 1번이 "[기본]" 태그임에도 실제 내용(포워딩된 값으로 BEQ 수행되는 경우의 버블 계산)은 기억 수준이 아닌 적용 수준입니다. LO-1(이해)와의 연결을 위한 순수 기억/이해 수준 문제("제어 해저드의 정의를 적으시오" 류)를 1번 앞에 한 문제 추가하는 것을 고려할 수 있으나, 대상 독자(대학원생) 수준을 감안하면 생략 허용.
