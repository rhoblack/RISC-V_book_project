## 2. 기술 의존성 순서 검토

### 필수 선행 관계 (위반 시 Critical)

```
Ch02 (레지스터/메모리 모델)
    → Ch03 (ISA 분석)        ✅ 올바른 순서
    → Ch04 (ALU/레지스터파일) ✅ ISA 이해 후 구현
    → Ch05 (메모리 서브시스템) ✅ Ch04와 병렬 가능
    → Ch06 (디코더/통합)      ✅ Ch04+Ch05 완료 후
    → Ch07 (파이프라인 기초)   ✅ 단일 사이클 이해 후
    → Ch08 (데이터 해저드)     ✅ 파이프라인 구조 이해 후
    → Ch09 (제어 해저드)       ✅ Ch08 스톨 메커니즘 이해 후
    → Ch10 (통합)             ✅ Ch08+Ch09 완료 후
    → Ch11-13 (캐시)          ✅ 파이프라인 스톨 신호 이해 후
    → Ch14 (AHB)             ✅ 캐시-메모리 인터페이스 이해 후
    → Ch15 (APB)             ✅ AHB 마스터/슬레이브 이해 후
    → Ch16 (예외/인터럽트)     ✅ 파이프라인+CSR 준비 후
    → Ch17-19 (FPGA)         ✅ 전체 설계 완료 후
```

**판정: 의존성 순서 이상 없음.**

## 4. Basys 3 FPGA 리소스 제약 분석

**대상 디바이스**: Xilinx Artix-7 XC7A35TCPG236-1

| 리소스 | 총량 | 예상 사용량 | 사용률 | 판정 |
|--------|------|-----------|-------|------|
| LUT6 | 20,800 | ~14,000 | ~67% | ✅ 여유 있음 |
| Flip-Flop | 41,600 | ~8,000 | ~19% | ✅ 충분 |
| BRAM 36Kb | 50개 | ~20개 | ~40% | ✅ 여유 있음 |
| DSP48E1 | 90개 | ~5개 | ~6% | ✅ 충분 |
| I/O | 100개 | ~30개 | ~30% | ✅ 충분 |

**BRAM 사용 내역 (예상)**:
- IMEM 4KB: 1개
- DMEM 8KB: 2개
- I-Cache 4KB: 1개
- D-Cache 8KB (2-way): 4개
- UART FIFO: 1개
- **소계**: ~9개 (여유 41개)

**판정**: Basys 3에서 전체 설계 구현 가능. 타이밍 목표 50MHz는 달성 가능성 높음.
