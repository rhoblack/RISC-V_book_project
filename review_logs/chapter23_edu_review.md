- 핵심 개념 요약 4가지 ✅ (879~891행): 슈퍼스칼라, 토너먼트, OOO, 2-이슈 설계

### 3. 인지 부하 분석

#### 최고 난이도 구간

23.3절이 최고 난이도 ✅ — 예약 스테이션, CDB, 레지스터 리네이밍, ROB 등 5개 이상 신규 개념.
강사 꿀팁(465~470행)에서 "완벽히 이해하지 못해도 성공"이라는 안심 문구 배치 ✅.

#### 메타인지 체크포인트 2회 배치

기획안: "예약 스테이션 설명 후" + "리네이밍 설명 후" 각 1회 = 총 2회

실제: 23.3절 내 `<aside class="metacognition">` **1회** (669~674행, ROB 커밋 순서 관련)

**판정**: 🟡 **1회 부족**. 기획에서 권장한 "예약 스테이션 역할을 한 문장으로 설명할 수 있나요?" 체크포인트가 누락됨. 예약 스테이션 설명(514~518행) 직후에 메타인지 체크포인트 1회 추가 권장.

#### 23.2↔23.3 사이 "쉬어가기"

기획안: "23.2절과 23.3절 사이에 중간 정리 삽입" 권장

실제: 별도의 중간 정리 절 없음. 대신 23.3절 서두의 강사 꿀팁(465~470행)이 난이도 경고 + 안심 문구 역할 수행.

**판정**: 🟡 **부분 이행**. 강사 꿀팁이 안심 문구를 제공하지만, 기획에서 권장한 "23.1~23.2 핵심 정리 + 패러다임 전환 안내"는 누락됨. 23.2절 끝(457행)과 23.3절 시작(462행) 사이에 2~3문장의 전환 문단 추가를 권장.

**문제점**: L1(기억), L2(이해), L3(적용) 수준의 기초 문제가 **전혀 없음**. 기획에서 제안한 "토너먼트 3대 구성요소 나열(L1)", "PHT 상태 전이 추적(L3)" 등이 연습문제에 포함되지 않음.

모든 문제가 L4 이상으로 편중되어, 중하위권 학생이 연습문제에 접근하기 어려울 수 있음. Part 9가 심화 챕터이더라도, 기초 회상/이해 문제 3~4개는 학습 확인에 필수.

**수정 권장**:
- 기존 11개 중 분석/평가 문제 3개를 L1~L3로 교체하거나, L1~L3 문제 3개를 앞에 추가하여 총 14개로 확장
- 기획안 4절의 L1 문제 1~3번, L3 문제 7번을 그대로 채택 가능
