---

## Ch19 개요

**제목:** 예외와 인터럽트 처리
**대상:** Verilog 경험 있는 대학원생
**선수 지식:** Ch18 CSR, Ch17 Timer/UART/GPIO, 파이프라인 기본(Ch09)

**핵심 신개념 (신규):**
1. 우선순위 인코더 (8개 소스 → 1개 cause_code)
2. 벡터화 주소 계산 (mtvec + cause << 2)
3. Trap Handler 호출 및 CSR 자동 저장
4. 중첩 인터럽트 처리 (MPIE 스택)

### Task 4: 연습문제 설계

**분량:** 5~7개 문제
**분포:** Remember 1~2개, Understand 2~3개, Apply 1~2개, Analyze 1~2개

**예시:**

1. **(Remember)** RISC-V mcause 레지스터에서 인터럽트 비트 위치는?
   - A) [30:0] B) [31] C) [30:26] D) [31:27]

2. **(Understand)** mtvec MODE=1 (Vectored)에서 MTIP(4번 인터럽트)의 핸들러 주소는?
   - 계산식: mtvec[31:2] + (4 << 2) = mtvec[31:2] + 16

3. **(Apply)** 다음 우선순위 인코더 코드의 버그를 찾으세요:
   ```
   // 하드웨어 우선순위: MEIP > MTIP > MSIP
   assign cause = meip ? 4'hB : (mtip ? 4'h7 : (msip ? 4'h3 : 4'h0));
   ```
   [답: 우선순위 순서가 틀림 — MTIP이 MEIP보다 우선이어야 함]

4. **(Analyze)** 중첩 인터럽트 상황:
   - t=0: MTIP 발생 → trap_enable → mepc=0x100, mcause=0x80000007
   - t=5: handler 내에서 MIE 재활성화, 동안 MSIP 발생
   - 스택 저장: mepc'=?, mcause'=?, mstatus'=?
