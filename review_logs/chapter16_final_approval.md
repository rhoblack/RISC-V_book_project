## 수정 확인 사항

| 수정 항목 | 지시 내용 | 반영 여부 |
|---------|---------|---------|
| C1 | addr_lat 래치 조건 `state == M_IDLE && cache_req`으로 변경 | ✅ 확인 (라인 602, 1470) |
| C2 | C1 수정으로 자동 해소 (wdata_lat 오류 연동) | ✅ 자동 해소 확인 |
| C3 | WAIT_CYCLES 파라미터 주석 재정의 + 2사이클 지연 설명 박스 추가 | ✅ 확인 (라인 757~769) |
| C4 | `initial` 블록 추가로 메모리 시뮬레이션 초기화 처리 | ✅ 확인 (라인 851) |
| M1 | M_DATA 상태에서 HREADY=1 확인 후 M_DONE 전이 | ✅ 확인 (라인 1488) |
| M2 | HREADY MUX 단일 전송 패턴 제한사항 주석 추가 | ✅ 확인 (라인 990) |
| M5 | SVA `|=>` → `|->` 수정 (SVA 1번, 2번 모두) | ✅ 확인 (라인 1218, 1227) |

| E2 | HTRANS 표 앞 BUSY/SEQ 미사용 안내 문구 추가, 표 하단 tfoot 안내 추가 | ✅ 확인 (라인 270, 313~314) |
| P2 | 16.5절 tip 박스에 실패 정상화 문구("통과의례") 추가 | ✅ 확인 (라인 712) |

## 품질 평가

- 기술 정확성: ⭐⭐⭐⭐⭐
  - C1(addr_lat 래치 타이밍), C3(Wait State 수), C4(메모리 초기화), M1(M_DATA HREADY), M2(HREADY MUX 제한사항), M5(SVA `|->`) 모두 수정 완료. AHB-Lite 프로토콜 준수 수준 최상.
- 초보자 이해도: ⭐⭐⭐⭐⭐
  - Ch15 대응표, USB 비유, 타이밍 다이어그램 단계별 설명, 메타인지 박스 5개, 빈칸 채우기 정답 장치(`<details>`) 완비. 초보자 독자 만점 평가 확인.
- 교육 설계: ⭐⭐⭐⭐⭐
  - E1(16.4절 중간 정리 박스), E2(HTRANS 표 배치 순서 개선) 수정으로 ⭐⭐⭐⭐ → ⭐⭐⭐⭐⭐ 격상. 블룸 L2~L5 포괄 연습문제 구성 유지.
- 심리적 안전성: ⭐⭐⭐⭐⭐

- 강의 적합도: ⭐⭐⭐⭐⭐

## 편집장 코멘트

Chapter 16은 RISC-V 교재 전체에서 처음으로 산업 표준 버스 프로토콜을 본격 다루는 챕터로, 학습 난이도와 기술 정밀도 요구 수준이 모두 높다. 기술 리뷰어가 지적한 4건의 Critical 이슈 — 특히 C1(addr_lat 래치 타이밍 오류)과 M5(SVA `|=>` → `|->`) — 는 독자가 교재 코드를 실제로 시뮬레이션할 때 오동작을 유발할 수 있는 심각한 오류였으나, 기술 저자가 이를 정확히 수정하였다.

교육 측면에서도 주목할 만한 성과가 있다. Ch15 자체 프로토콜과 AHB-Lite 신호의 1:1 대응표는 완전히 새로운 도메인 진입에 따른 학습 불안을 효과적으로 낮추며, "친숙한 개념의 표준화"라는 프레이밍이 독자 동기 유지에 크게 기여한다. 타이밍 다이어그램 단계별 설명과 FSM 상태별 텍스트 설명의 조합은 이 챕터의 핵심 교육 자산이다.

수정 권고 항목(B1~B4, E3~E5, P3~P4, I4~I5) 중 일부는 다음 수정 사이클에서 여건이 허락하는 범위에서 반영하기를 권장하나, 현 상태만으로도 Ch17 이후 학습에 필요한 AHB-Lite 기초 역량을 완전히 전달할 수 있다고 판단한다.
