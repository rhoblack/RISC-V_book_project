## 🔗 신규 개념별 비유/예시 & 한계 명시

### 17.1 — APB: "이면도로(로컬 도로)"

**비유**:
- **AHB (고속도로)**: 고속, 광대역(32비트), 많은 신호 (HADDR, HWRITE, HWDATA, HRDATA, HREADY, HRESP, HBURST, HSIZE...)
- **APB (이면도로/로컬 도로)**: 저속, 좁은 폭(보통 8/16비트), 간단한 신호 (PADDR, PWRITE, PWDATA, PRDATA, PREADY)
- **용도**: 빠른 응답이 필요 없는 UART, GPIO, Timer 같은 "저속 주변장치" 연결

**한계 명시**:
> "APB는 고속도로처럼 넓지 않으니 한 번에 여러 기기를 연결할 수 없다. 따라서 PSEL 신호로 하나씩 선택해야 한다."

**하드웨어 복귀**: PSEL (Peripheral Select) = mux 신호, 주소 범위로 자동 디코딩

### 17.2 — AHB-to-APB Bridge: "여행사(프로토콜 변환)"

**비유**:
- 영국(AHB: 영어, 좌측 통행)에서 일본(APB: 일본어, 우측 통행)으로 가려면 **여행사가 언어와 교통 규칙을 변환** (FSM)
- **단계**:
  1. AHB 신호(영어) 수신 → 2. 내부 메모리 기록(번역 메모) → 3. APB 신호(일본어) 송신 → 4. 응답 수신

**한계 명시**:
> "브리지는 AHB과 APB 두 프로토콜을 이해해야 하므로 가장 복잡한 부분이다. 하지만 한 번 작동하면, 다음부터는 주변장치만 추가하면 된다."

**하드웨어 복귀**: FSM 상태 = {IDLE, WAIT, DONE}, 신호 래치 = addr_lat, wdata_lat

### 17.3 — UART FIFO: "대기실(큐)"

**비유**:
- **병렬 vs 시리얼**: 데이터는 병렬(8비트)로 들어오지만 FIFO를 거쳐 **시리얼(1비트씩)**로 출력
- **FIFO**: 대기실 같이 먼저 들어온 것부터 나간다 (First In First Out)
- **오버플로우**: 대기실이 가득 차면 더 이상 입장 불가 → 데이터 손실 위험

**한계 명시**:
> "FIFO 크기는 유한하므로, 송신 속도가 느리면 오버플로우 위험이 있다. 따라서 소프트웨어에서 FIFO 상태를 확인하고 조절해야 한다."

**하드웨어 복귀**: FIFO_FULL, FIFO_EMPTY 플래그, WR_PTR/RD_PTR (write/read pointer)

### 17.4 — GPIO: "집의 출입구(문)"

**비유**:
- **Input**: 문의 "내부→외부" 방향 설정 (집에서 외부 신호 감지, 예: 초인종)
- **Output**: 문의 "외부→내부" 방향 설정 (집에서 외부로 신호 전송, 예: 초인종 누르면 집 안 카메라 영상)
- **방향 레지스터**: 문을 "쌍방향"에서 "일방향"으로 물리적 잠금

**한계 명시**:
> "GPIO 핀은 반드시 입출력 중 하나로만 설정해야 한다. 두 개 이상의 출력이 같은 핀을 제어하려고 하면 하드웨어 손상(경합, Contention) 위험이 있다."

**하드웨어 복귀**: DIR (Direction) 레지스터 = input/output 선택, tri-state buffer 제어

### 17.5 — Timer: "모래시계"

**비유**:
- **카운터**: 모래가 떨어지는 속도 (클록 신호)
- **비교값(CMP)**: 목표 시간 설정 (카운터 == CMP일 때 알람)
- **인터럽트**: 모래가 다 떨어졌을 때 울리는 종소리 (신호 발생)

**한계 명시**:
> "타이머는 정확하지 않을 수 있다. 예를 들어, 다른 인터럽트 처리 중에 타이머 인터럽트가 올 수 있고, ISR이 오래 걸리면 다음 인터럽트를 놓칠 수 있다. 이를 '타이밍 재진입(reentrancy)' 문제라 한다."

**하드웨어 복귀**: COUNTER (카운터 레지스터), CMP (비교 레지스터), CNT_ENABLE (카운터 시작/정지), IRQ (인터럽트 요청)

## 💡 기술 저자 집필 가이드 (기술 리뷰어 사전 경고)

### Critical(기술 오류) 방지 체크리스트

1. **APB 신호 폭**: 대부분 8비트 (Basys 3에서는 32비트 지원 가능, 명시할 것)
2. **AHB→APB 변환 타이밍**:
   - AHB: 전송 = HADDR (T0) + HWDATA (T1에 T0 주소로 쓰기)
   - APB: 전송 = 2사이클 (PSEL+PENABLE T0, PREADY 대기 T1)
   - **변환 규칙 명시 필수** (라이팅 시간 증가 이유)
3. **UART 보드레이트 생성기**: 클록 분주 공식 명시 (예: clk_div = sys_clk / (16 × baud_rate) - 1)
4. **GPIO 방향**: 입출력 동시 설정 금지 (경합 위험)
5. **Timer CMP 계산**: 클록 주파수 명시 필요 (예: sys_clk = 50MHz일 때 CMP = 5M × 주기(초))

### Major(비효율) 가능성

1. **UART FIFO 크기**: 4~8개 엔트리 제안 (Basys 3 BRAM 효율)
2. **GPIO 핀 매핑**: Basys 3 LED 4개, 스위치 4개 명시 + XDC 파일 제공
3. **Timer 정밀도**: 16비트 vs 32비트 선택 및 근거 필요
4. **클록 분배**: 모든 주변장치가 sys_clk 또는 분주 클록 사용 명시

### 초보자 독자 고려사항

1. **새 단어**:
   - FIFO = First In First Out (맨 처음 들어온 것이 맨 처음 나간다)
   - Handshake = 손을 맞잡듯이 신호를 주고받는 것
   - 보드레이트(Baud Rate) = 1초에 몇 비트를 보내는가 (예: 115200 = 초당 115200비트)

2. **SVG 지도**: 각 절에서 "지금 설계하는 부분"을 전체 블록 다이어그램에 하이라이트

3. **코드 예제**: SystemVerilog 고착 (수동 마스터/슬레이브 모듈, testbench 포함)
