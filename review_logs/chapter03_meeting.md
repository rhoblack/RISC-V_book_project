- **상태**: ✅ 반영 완료

**[CRITICAL-2] 3.5절: B-type 즉치수 비트 재배열 단계별 설명**
- **상태**: ✅ 반영 완료
- **반영 위치**: 3.5절 전체

  - 6단계 재조합 순서 목록 제공

  - instructor-tip 박스에서 강의 방법론 4단계 제시
  - interview 박스에서 면접 포인트로 B-type vs S-type 차이 설명

**[CRITICAL-3] 3.8절: JAL은 J-type, JALR은 I-type. 즉치수 계산 방식 구별**
- **상태**: ✅ 반영 완료
- **반영 위치**: 3.8절 전체
- **확인 내용**:
  - 절 도입부에서 JAL = J-type 명시
  - "JALR은 J-type이 아니라 I-type입니다. 이 점을 자주 혼동합니다." 명시적 경고문 포함
  - JAL vs JALR 비교표: 명령어 형식, 점프 주소 계산, 즉치수 범위, opcode 모두 대조
  - JAL 즉치수 재조합 SystemVerilog 코드 제공

**[CRITICAL-4] 3.9절: FENCE는 NOP으로 처리 가능하나 이 결정을 명시할 것**

  - NOP 처리 결정의 근거 4가지 bullet point 제시 (단일 코어, in-order, DMA 없음, 캐시 일관성 불필요)
  - tip 박스에서 설계 문서화 방법과 SystemVerilog 주석 예시 포함
  - 3.11절 "구현 방침" 요약에도 재명시

#### Minor 이슈

**[MINOR-1] 3.7절 LUI + ADDI 예시 주석 길이**
- 32비트 상수 생성 예시의 코드 주석이 다소 장황하지만, 교육 목적으로 상세 설명이 적절하다고 판단.
- 수정 불필요.

**[MINOR-2] 3.10절 RARS 어셈블리 코드에서 언어 클래스**
- 어셈블리 코드 블록에 `language-systemverilog` 클래스가 적용되어 있으나, 어셈블리에 맞는 클래스가 없으므로 하이라이팅 미적용 가능성. 기능에는 영향 없음.
- 수정 불필요 (CSS에서 기본 mono 폰트 적용됨).
