### C1 — `add x2, x2, x1` 머신코드 오류

**발견자**: 기술 리뷰어

**현황**:
- `code_examples/ch11_control_hazard_tb.sv` line 62: `32'h001101B3`
- `manuscripts/part4/chapter11.html` line 722: `32'h001101B3`
- 이 값은 실제로 `add x3, x2, x1` (rd=x3)로 디코딩됨
- 루프 실행 시 x2(sum)가 갱신되지 않아 무한 루프 발생

**수정 방향**:
- 올바른 값: `32'h00110133` (`add x2, x2, x1`: funct7=0, rs2=x1, rs1=x2, funct3=000, rd=x2, opcode=0110011)
- 테스트벤치 `.sv` 파일과 HTML 원고 코드 스니펫 모두 수정

### C2 — BNE 오프셋 오류

**발견자**: 기술 리뷰어

**현황**:
- `code_examples/ch11_control_hazard_tb.sv` line 70: `32'hFE3090E3`
- `manuscripts/part4/chapter11.html` line 724: `32'hFE3090E3`
- `0xFE3090E3`은 실제로 `bne x1, x3, -32` (offset=-32)로 디코딩됨
- 주석의 "offset=-12"도 오류: 실제 필요한 오프셋은 PC(0x14) → loop(0x0C) = **-8**

**수정 방향**:
- BNE at PC=0x14, loop at PC=0x0C → offset = 0x0C - 0x14 = -8
- -8의 B-type 인코딩: imm[12]=1, imm[11]=1, imm[10:5]=111111, imm[4:1]=1000 → `0xFE309CE3`
- 테스트벤치의 값과 주석(-12→-8) 모두 수정
- HTML 원고 코드 스니펫도 동일하게 수정

## Major 이슈 처리 계획

### M1 (기술) — BHT 성능 테이블 페널티 오류

**발견자**: 기술 리뷰어

**현황**:
- HTML 11.5절 성능 비교 표에서 BHT 행: "첫 반복 1회 오예측 → 2사이클"
- 실제: BHT 초기 상태 01(약한 미분기), 루프 10회 실행 시 **2회 오예측**
  - Exec 1: predict=NT(01), actual=T → MISS (상태 01→10)
  - Exec 2~9: predict=T, actual=T → HIT
  - Exec 10: predict=T(11), actual=NT → MISS (상태 11→10)
  - 총 2회 오예측 = **4사이클 페널티**
- 11.5절 aside.tip 본문 "첫 반복에서만 오예측이 일어나므로"도 오류

**수정 방향**:
- 표의 BHT 행 수정: "첫 반복 + 루프 탈출 시 2회 오예측" / "4사이클"
- aside.tip 본문의 해당 문장도 "첫 반복과 루프 탈출 시 2회 오예측이 일어나므로"로 수정

### M2 (기술) — 테스트벤치 커버리지 보강

**발견자**: 기술 리뷰어

**현황**:
- 헤더 주석에 4가지 시나리오 선언되어 있으나, 실제 구현은 시나리오 4(루프 마일스톤)만 존재
- BEQ taken flush 검증, BNE not-taken 검증, Load-JALR 해저드 검증 부재

**수정 방향**:
- 시나리오 1~3을 별도 태스크로 구현하여 추가
  - 시나리오 1: BEQ taken — flush 동작, wrong-path 제거 검증
  - 시나리오 2: BNE not-taken — 정상 실행, 플러시 없음 검증
  - 시나리오 3: Load-JALR hazard — 스톨 후 JALR 정상 실행 검증
  - 시나리오 4: 루프 마일스톤 (기존 유지)

### M3 (초보자) — `id_ex_jalr` 출처 설명 추가

**발견자**: 초보자 독자

**현황**:
- 11.6절에서 `assign jalr_taken_ex = id_ex_jalr;` 코드가 설명 없이 등장
- 이 신호의 생성 경로(디코더 → 제어 신호 → ID/EX 레지스터)가 불명확

**수정 방향**:
- `assign jalr_taken_ex = id_ex_jalr;` 코드 직후 또는 직전에
  "이 신호는 디코더가 JALR opcode를 감지하여 생성한 제어 신호가 ID/EX 파이프라인 레지스터를 통해 EX 스테이지로 전달된 것입니다" 1~2문장 추가

### M4 (심리) — 11.7절 테스트 실패 정상화 문구 추가
