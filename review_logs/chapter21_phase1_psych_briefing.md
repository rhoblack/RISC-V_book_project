## 3️⃣ 불안 지점 식별 및 완화 전략

### Top 3 불안 지점

#### 불안 지점 1: 공식 복잡성
- **증상**: "P = CV²f + I_leak×V 공식이 무섭다"
- **원인**: 수학적 기호가 많고 다변수
- **신호**: 학생이 공식 설명 파트를 건너뛸 수 있음
- **완화 전략**:
  1. **각 항을 일상 비유로 분해**
     - C (커패시턴스) = "전기 물탱크 크기"
     - V (전압) = "수압 세기"
     - f (주파수) = "움직임 빠르기"
     - I_leak (누설 전류) = "수돗물 틈새로 새는 물" (24시간, 전원 켜기만 해도)
  2. **"복잡해 보이지만..."** 문구 반드시 삽입
  3. **정량화 예시** 제공: "실제 계산해보면 동적 전력 60%, 정적 전력 40%"
  4. **도구 의존성** 명시: "직접 계산 안 해도 Vivado가 해줍니다"

#### 불안 지점 2: 발열 우려
- **증상**: "보드가 망가질까? 온도가 올라가면?"
- **원인**: 물리적 결과에 대한 두려움
- **신호**: "보드 손상" 관련 질문 빈번
- **완화 전략**:
  1. **정량 안전 정보** 공개
     ```
     Basys 3 안전 온도: 0~70°C
     실제 학생 설계 범위: 30~55°C (대부분)
     보호 메커니즘: 자동 thermal throttling (60°C 이상)
     ```
  2. **"안심하세요"** 문구 3회 이상 삽입 (21.5절)
  3. **실패 정상화**: "50℃가 넘었어도 보드 손상 없습니다"
  4. **경험담**: "지난 5년 학생 프로젝트 중 보드 고장 0건"

#### 불안 지점 3: 무기력감 ("왜 이걸 배워야 해?")
- **증상**: "전력 최적화는 나중에 배우는 거 아닌가?"
- **원인**: 실무 연결성 부족 + 이론만 있으면 권태
- **신호**: 연습문제를 급하게 풀려는 경향
- **완화 전략**:
  1. **면접 연결** 명시
     ```
     Top 5 "전력" 면접 질문:
     1. "당신 설계 전력 추정치는?"
     2. "동적 vs 정적 전력, 둘 다 중요한 이유?"
     3. "전력 최적화 경험이 있나?"
     4. "저전력 설계로 무엇을 배웠나?"
     5. "RTL 설계에서 전력을 고려하는 방법?"
     ```
  2. **현업 설계자 인용**
     ```
     "애플 칩 엔지니어: 우리는 매 시즌 전력 예산을 5%씩 줄여야 한다"
     "Tesla 칩팀: 전력 효율이 성능만큼 중요하다"
     ```
  3. **Part 1~8의 각 챕터와 연결**
     ```
     Ch01~05 (기본 구조) → 얼마나 전력 쓰나?
     Ch06~08 (단일/멀티/파이프라인) → CPI 개선 = 전력 절감
     Ch09~12 (포워딩/캐시) → 메모리 접근 ≠ 에너지 낭비
     Ch13~15 (캐시) → 효율 ↑ = 전력 ↓
     Ch16~18 (버스/주변기기) → 시스템 레벨 전력 관리
     Ch19 (인터럽트) → 폴링 vs 인터럽트 = 전력 대결
     Ch20 (합성) → 논리 레벨 최적화
     Ch21 (이 장) → 종합 설계 검증
     ```
