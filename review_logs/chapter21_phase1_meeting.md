### 4. 자기효능감 관리 (첫 실습 100% 성공 보장)

**Q1~Q3 기획** (100% 성공 보장, Remember→Apply):
- **Q1 (Remember)**: 공식 계산 → 계산기로도 가능 (100% 성공)
- **Q2 (Understand)**: 개념 이해 → 원고에서 직접 인용 가능 (95% 성공)
- **Q3 (Apply)**: Vivado Power Report → GUI 클릭 형식, 자동 계산 (90% 성공)

**Q4~Q6 기획** (50~70% 성공률, Analyze→Evaluate):
- **Q4 (Analyze)**: Trade-off 분석 → 당신이라면? (자기주도성 강화)
- **Q5 (Evaluate)**: 종합 설계 → 자신의 경험 기반 (자유 답변)
- **Q6 (Evaluate)**: 상황별 우선순위 → 의사결정 기술 (종합 사고)

### 5. 비유 설계 (5개 + 한계 명시 + 대안)

| 개념 | 비유 | 기술 사실 매핑 | 한계 | 대안 비유 |
|------|------|-------------|------|---------|
| **동적 전력** | 자동차 가속 | V²=강도, f=빈도 | 자동차는 선형(연비), 반도체는 V² 지수 | 춤추는 사람: 빠르고 강할수록 에너지↑ |
| **정적 전력** | 아이들링 자동차 | 움직이지 않아도 연료 소비 | 누설은 온도/전압에 의존, 선형 아님 | 뜨거운 엔진: 온도차로 열 손실 |
| **PPA 트레이드오프** | 요리 시간/맛/가격 | 시간↔품질↔비용 삼각 관계 | 요리는 보통 선형, 개인화 필요 | 공부: 시간/성적/건강 (학생 경험) |
| **열 관리** | 냉각팬 필터 청결 | 청결↔바람↔소음 | 필터는 재사용 가능, FPGA는 불가 | 냉각팬 RPM 조절: 항상 도는 게 정상 |
| **DVFS** | 자동차 순항 속도 | 느린 속도(저주파)→저전력 | 변속 오버헤드 있음, 모든 회로 가능한 건 아님 | 자전거 기어 변속: 오르막길에서 저기어 |

### 10. 손 실습: Vivado 전력 분석 (Q3 Apply, 30분)

**목표**: 학생이 Vivado를 사용해 자신의 설계 전력을 측정하고 도구 신뢰성 이해

**Step 1**: Vivado 프로젝트 열기 (2분)
- 이미 합성된 Ch20 프로젝트 사용 (시간 절약)

**Step 2**: Power Report 생성 (1분)
- Tools → Power → Report Power → Generate

**Step 3**: 결과 분석 (3분)
```
Dynamic Power:    0.352W
Static Power:     0.148W
Total:            0.500W
```
강사: "우리 설계의 동적이 70%, 정적이 30%. 왜 70:30일까? 100MHz에서 돌고 있으니까요!"

**Step 4**: 학생 직접 시행 (10분)
- 각자 Power Report 스크린샷 저장, 숫자 기록
- 강사: 돌아다니며 피드백 ("좋네, 0.5W 나왔어?")

**Step 5**: 비교 분석 (5분)
- 칠판에 수치들 적기: A(0.48W), B(0.51W), C(0.47W) ← 최고!
- "C가 0장 다른 이유는?" → 자연스럽게 21.5절로 연결

**실습 이후 발문**:
- "Vivado 0.5W를 100% 믿어도 될까?" → ±10% 오차
- "반도체로 만들면 같을까?" → Post-layout, 온도 효과
- "0.5W를 0.2W로 줄 수 있을까?" → 최적화 기법들
