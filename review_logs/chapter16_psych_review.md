## 불안 지점 분석 (Pain Points)

### P1: AMBA 계보 + 11개 신호의 신비성 (16.1~16.2)
- **위험도**: 🟡 중간 (초반부 불안 상승)
- **완화 상태**: ✅ 우수
  - 비유 "USB 표준" (호환성 문제)로 **왜** 표준이 필요한지 명확
  - 신호를 3그룹(A: 주소/제어, B: 데이터, C: 흐름제어)으로 **체계적 분류**
  - Table: "Ch15 신호 ↔ AHB 신호 대응" (친숙한 것을 새 표준으로 프레이밍) ← 핵심!

### P2: 1사이클 파이프라인 타이밍 (16.3~16.4)
- **위험도**: 🔴 높음
- **완화 상태**: ✅ 우수
  - **Ch09 파이프라인 회상**: "IF에서 읽는 동안 ID에서 디코딩" → AHB도 동일
  - 비유 "고속도로의 신호등" (Wait State 직관)
  - 비유 한계 명시 ("양방향 전송, 단일마스터만")
  - SVG 타이밍 다이어그램 존재 ✅

### P3: FSM 상태 전이의 정확성 (16.5)
- **위험도**: 🟡 중간
- **완화 상태**: ✅ 우수
  - **실무 팁**: "HWDATA 타이밍 오류는 모든 설계자가 겪는 통과의례" ← 정상화 완벽 ⭐
  - "이 오류를 발견하고 수정한 순간, AHB를 진정으로 이해" (변증법적 학습)
  - addr_lat, write_lat, wdata_lat 래치 메커니즘 명확

### P4: 슬레이브 Wait State FSM (16.6)
- **위험도**: 🟢 낮음
- **완화 상태**: ✅ 우수
  - "WAIT_CYCLES=1" vs "총 2사이클" 혼동 선제적 예방 (FAQ)
  - S_IDLE → S_WAIT → S_DONE 직관적 상태명

### P5: 인터커넥트 HSEL_d 타이밍 (16.7)
- **위험도**: 🔴 높음 (가장 심화된 개념)
- **완화 상태**: ⚠️ 좋음 (완벽하지는 않음)
  - 텍스트 설명 명확
  - 면접 포인트 Q&A 제시 ✅
  - **미개선**: SVG 그림 16-5에 "1사이클 지연" 시각 표시 필요
