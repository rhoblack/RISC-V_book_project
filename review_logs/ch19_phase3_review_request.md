## Reviewer 1: 기술 리뷰어 (Technical Reviewer)

### 임무
SystemVerilog 코드 정확성, RISC-V ISA 준수, Basys 3 적합성 검증

### 검토 사항

#### 1. 코드 정확성 (3개 모듈)
- **ch19_exception_unit.sv** (~250줄)
  - 동기 예외 감지: Illegal Instr(ID), Misaligned(EX), ECALL(ID)
  - 예외 태깅 메커니즘 (발생 스테이지별 우선순위)
  - 합성 가능성 (Vivado로 검증 가능한가?)

- **ch19_trap_controller.sv** (~200줄)
  - 6단계 시퀀스: except_detected → mepc_save → mcause_update → mtvec_fetch → pc_redirect → handler_enter
  - CSR 인터페이스 정확성 (mtvec, mepc, mcause 레지스터 접근)
  - WB 커밋 모델 (정확한 예외 보장)

- **ch19_exception_tb.sv** (~300줄)
  - 4개 시나리오: ECALL, Misaligned Load, Timer Interrupt, CSR Hazard
  - 파형 검증 (VCD 파일 생성)
  - 응답 시간 측정 (사이클 단위)

#### 2. RISC-V ISA 준수
- mcause 코드: Illegal Instr=2, Load Misaligned=4, ECALL=11, Timer IRQ=31
- mtvec 레이아웃: mtvec[31:2]=핸들러 기본 주소, mtvec[1:0]=모드 (직접=0)
- mstatus MIE 비트: 글로벌 인터럽트 활성화

#### 3. 파이프라인 통합 정확성
- 5단계 파이프라인 각 스테이지에서의 예외 감지 (IF/ID/EX/MEM/WB)
- flush 신호: 예외 발생 시 IF/ID/EX/MEM 스테이지 무효화
- WB 스테이지: 가장 나중 명령어가 커밋되어야 정확한 예외 보장
- 우선순위: WB > MEM > EX > ID > IF (가장 나중 스테이지 우선)

#### 4. 분류 및 출력

분류: 🔴 Critical(기술 오류/합성 불가) · 🟡 Major(비효율/표준 미준수) · 🟢 Minor(스타일)

**출력**: review_logs/chapter19_tech_review.md
- 절별 기술 문제 (있으면)
- 코드 부분 인용 + 수정안
- Critical 0건, Major 0건 목표

## Reviewer 5: 교육전문강사 (Expert Instructor)

### 임무
설명 품질, 비유 검증, 면접 포인트, 강의 적합도

### 검토 사항

#### 1. 설명 품질
- 각 절의 설명이 강의에서 그대로 쓸 수 있는 수준인가?
- 예: "정확한 예외란 가장 나중 명령어의 예외만 처리하고, 앞의 명령어는 모두 커밋하는 것"

#### 2. 비유 검증
비유 4개 (공장 비상벨, 소방 조직도, 은행 금고, 항공기 블랙박스):
- ① 기술 사실과 정확히 매핑되는가?
- ② 한계가 명시되었는가? ("비유는 ___이지만, 실제로는 ___")
- ③ 오해 유발 여부 (혼동 가능성)
- ④ 필요시 대안 비유

#### 3. 수강생 막힘 포인트
- 어디서 질문이 많이 나올까?
  - 19.5의 "정확한 예외" 개념? (동시성 + 우선순위)
  - 19.3의 "mie/mip 매칭"? (비트 연산)
  - 19.6의 "CSR 해저드"? (파이프라인 + CSR 상호작용)

#### 4. 면접 연결 포인트
- 동기/비동기 예외의 차이 (자주 출제)
- 정확한 예외와 부정확한 예외의 차이 (하드웨어 설계 인터뷰)
- CSR 해저드 처리 방법 (시스템 설계)

#### 5. 강의 실습 계획
- 19.6 테스트벤치가 실제 실습으로 가능한가?
- 대학 1학기에 구현 가능한 난이도?

**출력**: review_logs/chapter19_instructor_review.md
- 절별 설명 품질 평가
- 비유 4개 검증 (① 정확성 ② 한계 ③ 오해 ④ 대안)
- 막힘 포인트 3~4개 + 해결 방법
- 면접 포인트 3개 + 설명 개선
- 강의 적합도 평가 (⭐⭐⭐⭐⭐ 목표)
