  - 시각적 호기심 유발 (적외선 카메라 = 미스터리)

- **장치**: P = CV²f 공식 도입, 복잡해 보이는 파라미터 3개

## C. 불안 완화 메시지 배치 분석

### 불안 지점별 완화 문구 (8가지 × 정확한 위치)

#### 1. 공식 복잡성 → 불안 완화 ✅
- **위치**: 21.1절 "복잡해 보이지만, 각 항(V, f, C)은 물리적 의미가 명확합니다"
- **톤**: 안심 + 정보 (수학적 신뢰성)
- **효과성**: ⭐⭐⭐⭐⭐ (즉시 불안 해소)

#### 2. V²f 비직관성 → 불안 완화 ✅
- **위치**: 21.1절 "차원 분석: [F]×[V²]×[Hz]=[Watt]"
- **추가**: 춤 비유에서 "V²이므로 제곱으로 증가"
- **효과성**: ⭐⭐⭐⭐⭐ (수학적 증명 + 비유)

#### 3. 발열 물리적 두려움 → 불안 완화 ✅
- **위치**: 21.5절 "Tj_max=85°C, 실측 30~55°C, 안전"
- **추가**: "Basys 3는 자동 보호 메커니즘 내장"
- **톤**: 정량적 근거 (숫자는 안심 제공)
- **효과성**: ⭐⭐⭐⭐⭐ (구체 수치로 공포 제거)

#### 4. 도구 신뢰도 의심 → 불안 완화 ✅
- **위치**: 21.4절 "Vivado Power Report ±10~15% 오차는 산업 표준"
- **톤**: 투명성 (한계 명시 = 신뢰)
- **효과성**: ⭐⭐⭐⭐ (상대 비교 중심으로 전환)

#### 5. "PPA 선택 불안" → 불안 완화 ✅
- **위치**: 21.3절 "정답은 없다. 우선순위 문제"
- **톤**: 도덕화 (선택의 자유 인정)
- **효과성**: ⭐⭐⭐⭐⭐ (무기력감→주체성으로 전환)

#### 6. 기법 5가지 과다 → 불안 완화 ✅
- **위치**: 21.4절 "모두 쓸 필요는 없다. 상황에 맞게 선택"
- **톤**: 명확한 허용 (오버로드 완화)
- **효과성**: ⭐⭐⭐⭐⭐ (선택압 제거)

#### 7. 온도 폭주(thermal runaway) → 불안 완화 ✅
- **위치**: 21.5절 "보드의 자동 보호 회로가 온도 폭주 방지"
- **톤**: 메커니즘 설명 (통제감 제공)
- **효과성**: ⭐⭐⭐⭐ (기술적 안전장치)

#### 8. 측정 신뢰도 불명확성 → 불안 완화 ✅
- **위치**: 21.2절 "±10~15% 오차, 원인 명시"
- **추가**: 21.3절 EPI 정의로 상대 비교 강조
- **톤**: 투명성 (한계 인정 = 전문성)
- **효과성**: ⭐⭐⭐⭐ (예상 가능한 범위 제시)

**종합**: 불안 8가지 × 정확한 위치 배치 = 심리적 안전성 극대화 ✅

- **심리 효과**: 도구 신뢰도 유지 + 실패 정상화 ✅

#### 위치 3: 21.5절 "발열 걱정하면서도 측정 못하면 불안"
- **맥락**: 실습 후 "그런데 정말 안전할까?" 불안

- **심리 효과**: 혼자가 아니라는 메시지 ✅

## 최종 평가

### 강점 (모두 유지 필수)

✅ **감정 곡선**: 5단계 명확 + 구현 구체적
- 호기심(적외선 카메라) → 혼란(공식) → 불안(발열/기법) → 이해(Vivado) → 성취(완주)

✅ **불안 완화**: 8가지 불안 × 정확한 배치
- 각 불안마다 구체적이고 정량적인 완화 메시지

✅ **자기효능감 관리**: Q1~Q3 100% 성공 + Q4~Q6 분화
- 초기 확신 구축 후 점진적 도전 제시

✅ **비유 검증**: 춤/자동차/요리/냉각팬/DVFS
- 모두 기술 사실과 매핑 정확 + 한계 명시

✅ **메타인지**: 각 절 마지막 자기점검 질문
- 학습 통합 촉진

### 개선 필요 사항

⚠️ **21.4절 신규 개념 5개 분할 권장** (교육설계자 지적)
- 현재: DVFS, Clock Gating, 메모리최적화, 파이프라인, 병렬화 (5개 + 조합론)
- 문제: 불안 상태에서 5개는 과부하
- **권장 해결**: 섹션 분할 (21.4A: 동적+정적 조절 / 21.4B: 아키텍처 기법) 또는 "모두 선택할 필요 없음" 메시지 강화
- **심리 영향**: 현재 "상황별 선택" 메시지로 부분 완화됨
