## 1. 각 리뷰어 핵심 피드백 요약

### 기술 리뷰어
- **Critical**: C-1 리셋 극성 불일치(Basys 3 버튼 액티브 하이 vs rst_n 액티브 로우)
- **Major**: M-1 듀얼 에지 설명 오류, M-2 cin 확장 비직관적, M-3 cout 기대값 가독성, M-4 led_blinker 두 버전 혼동, M-5 FSM WAIT 상태 unreachable, M-6 led_blinker_tb에 self-checking 없음
- **Minor**: MUX 관례 반전, XDC/VCS 코드 블록 language 오류, $clog2 슬라이싱 복잡, 1'b1/26'd1 불일치
- **종합 점수**: 기술 정확도 4/5, 코드 합성 가능성 5/5, Basys 3 적합성 3/5

### 초보자 독자
- 전체 이해도: ⭐⭐⭐⭐ (대부분 이해 가능, 일부 보강 필요)
- **핵심 문제점**: SoC 구성 요소 목록에서 압도감, $clog2/'0/task automatic/$urandom 등 설명 없는 용어 다수
- **"여기서 막힘" 포인트**: 1.1절 SoC 목록, 1.4절 분주 설명 오류, 1.5절 $clog2 미설명, task automatic 미설명
- **긍정적 평가**: 1.3절 Verilog/SV 대비 구성 탁월, 레고/변속기 비유 효과적

### 교육심리전문가
- **종합 점수**: ⭐⭐⭐⭐ (심리적 안전성 3.8/5)
- **감정 곡선**: 전체적으로 호기심→불안→안정→성취감 패턴 부합
- **핵심 개선**: 1.2절 설치 중 실패 정상화(psychological inoculation) 메시지 부재, 1.3절 코드 연속 구간 중간 격려 부족, 실패 정상화 점수 3.0/5로 가장 낮음

### 교육전문강사
- **강의 적합도**: 4.5/5
- **핵심 개선**: 비유의 한계점 미명시(레고, 변속기), 1.3→1.4절 연결 문장 부재, FSM WAIT dead state
- **긍정적 평가**: 강의 현장에서 거의 그대로 사용 가능한 수준, LED 성취감 설계 우수

## 3. Action Items

### 반영할 것 (이번 수정에 포함)

1. **[C-1]** 리셋 극성 불일치: XDC에 버튼 극성 설명 추가 + 코드에 인버터 로직 추가 + 본문에서 교육적 설명
2. **[M-1]** 분주 설명 오류: "상승/하강 에지 모두 사용" 삭제, 정확한 설명으로 교체
3. **[M-2]** simple_adder cin 간소화: `{31'b0, cin}` → `cin`
4. **[M-3]** cout 기대값: `>> 32` → `[32]` 비트 선택
5. **[M-5]** FSM WAIT 상태: RUN → WAIT → DONE 전이 경로 추가
6. **[M-6]** led_blinker_tb self-checking: 리셋 후 assertion 추가
7. **[M-7]** 1.1절 "지금 모르는 용어가 있어도 괜찮다" 안내 추가
8. **[M-8]** $clog2 함수 설명 추가
9. **[M-9]** 1.3→1.4절 연결 문장 추가
10. **[M-10]** 1.2절 사전 면역 메시지 추가
11. **[M-11]** 1.3절 중간 격려 문구 추가
12. **[M-12]** 레고/변속기 비유 한계점 한 문장씩 추가
13. **[M-13]** 용어 설명 추가: $clog2, '0, task automatic, $urandom/$urandom_range, LUT/FF, 넷리스트, LVCMOS33, CSR 풀이
14. **[m-2]** XDC 코드 블록 language-systemverilog → language-tcl
15. **[m-3]** VCS 코드 블록 language-systemverilog → language-bash
16. **[m-4]** $clog2 슬라이싱 간소화: counter == COUNT_MAX로 변경, 비트 폭 경고 주석 설명
17. **[m-5]** 카운터 증분 1'b1로 통일 (1.4절 26'd1 → 1'b1)

### 보류할 것 (이번 수정에서 제외)

1. **[M-4]** led_blinker 두 버전의 모듈명 혼동: 현재 구조가 "비파라미터화 → 파라미터화로 발전"의 교육적 흐름을 의도한 것이므로, 1.5절에서 연결 문장을 강화하는 선에서 해결
2. **[m-1]** MUX 관례 반전 (sel=1→a): 기술적 오류가 아니며, 수정 시 코드 전체 재검증 필요
3. 면접 포인트에 always_latch 추가: 분량 확대 우려, 후속 챕터에서 다룰 기회 있음
4. 추가 강사 꿀팁/FAQ 제안: 우수한 제안이나 분량 조절을 위해 2차 수정 시 반영 검토
