### A. 기술 리뷰

#### Critical 이슈 검토 결과

기술 리뷰어가 사전에 제시한 3개의 Critical 주석에 대한 반영 여부를 확인합니다.

**[CRITICAL-1] 레지스터 파일: 동기 읽기(BRAM) 시 1사이클 지연 발생 → 단일 사이클 동작 불가**
- **상태**: ✅ 반영 완료
- **반영 위치**: 4.3절 전체 ("동기 쓰기 / 비동기 읽기: FPGA 합성의 핵심 선택" 소절)
- **확인 내용**:
  - "단일 사이클 프로세서에서 이는 치명적 문제입니다." 명시적 경고문 포함
  - BRAM(동기 읽기)이 1사이클 지연을 유발하여 단일 사이클 동작이 불가능함을 설명
  - 비동기 읽기(분산 RAM/LUTRAM) 선택 근거를 교육적으로 서술
  - 면접 포인트 박스에서 "BRAM vs 분산 RAM" 트레이드오프를 명시
  - 강사 꿀팁 박스에서 타이밍 다이어그램 강의법 제시
  - 코드 주석에 "단일 사이클 프로세서에서 동기 쓰기(BRAM) 사용 시 1사이클 지연 발생 → 비동기 읽기 필수" 명시
  - 합성 보고서에서 RAM32M/RAM32X1D 프리미티브 확인 방법 안내

**[CRITICAL-2] ALU: $signed 캐스팅을 SRA와 SLT에 올바르게 적용**
- **상태**: ✅ 반영 완료
- **반영 위치**: 4.2절 "시프트 연산: SLL, SRL, SRA" 소절 및 "비교 연산: SLT와 SLTU" 소절
- **확인 내용**:
  - SRA: `$signed(a) >>> b[4:0]` 적용, "반드시 $signed() 캐스팅을 적용해야 합니다" 강조문 포함
  - "$signed() 없이 `a >>> b[4:0]`으로 쓰면 SRL과 동일하게 동작" 경고 명시
  - SLT: `$signed(a) < $signed(b)` 적용
  - SLTU: 캐스팅 없이 `a < b` (무부호 비교) — 올바른 구분
  - 코드 내 한국어 주석으로 각 연산 설명 포함
  - "$signed() 캐스팅 주의 사항" tip 박스에서 교육적 설명 추가
  - 4.6절 "주요 SystemVerilog 패턴 정리"에서 $signed() 재강조
  - 연습문제 [분석] 문항에서 $signed 미적용 시 오류 케이스 분석 요구

**[CRITICAL-3] 즉치수 생성기: B-type과 J-type의 LSB가 항상 0임을 주석으로 명시 (명령어 정렬 원칙)**
- **상태**: ✅ 반영 완료
- **반영 위치**: 4.4절 "B-type과 J-type: LSB가 항상 0인 이유" 소절 및 코드 주석
- **확인 내용**:
  - 코드 주석: "LSB(imm[0])는 항상 0 — 명령어는 반드시 2바이트 정렬" 두 곳 명시
  - 전용 소절에서 명령어 정렬 원칙을 교육적으로 설명
  - FAQ 박스에서 "1'b0을 마지막에 붙이는 이유" 심층 답변
  - 4.6절 "설계 결정 근거 요약"에서 재명시

#### Minor 이슈

**[MINOR-1] 즉치수 생성기 테스트벤치 J-type 케이스 미포함**
- J-type 즉치수 검증이 누락되었습니다. 그러나 B-type이 더 복잡한 재조합 구조를 가지며,
  J-type과 동일한 원칙(재조합 + LSB=0)을 따르므로 B-type 검증으로 핵심 패턴을 커버합니다.
- 교육적 보완: 연습문제 [적용] 항목에서 B-type 즉치수 수동 계산을 요구하여 이해도를 확인합니다.
- 수정 불필요 (교육 범위 내에서 충분).
