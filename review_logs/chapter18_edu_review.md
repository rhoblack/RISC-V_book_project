## 상세 평가

### 1. 학습 목표 7개의 블룸 분류 분포

**평가: 양호**

| 번호 | 내용 요약 | 선언 수준 | 실제 수준 | 적합도 |
|------|-----------|-----------|-----------|--------|
| 1 | Machine Mode 특권 수준 역할 설명 | L2 이해 | L2 | 적합 |
| 2 | CSR 주소 공간·접근 권한 설명 | L2 이해 | L2 | 적합 |
| 3 | 7개 핵심 CSR 비트 필드 기술 | L2 이해 | L2~L3 | 약간 낮게 선언 |
| 4 | csr_unit 모듈 구현 | L3 적용 | L3 | 적합 |
| 5 | CSR 명령어 6종 원자적 동작 구현 | L3 적용 | L3 | 적합 |
| 6 | 인터럽트 마스킹 로직 분석·설계 | L4 분석 | L4 | 적합 |
| 7 | Ch19 연결 CSR 인터페이스 설계 | L4 분석 | L4 | 적합 |

**총평**: L2×3, L3×2, L4×2 분포입니다. 블룸 분류 기준 L1(기억)이 없고, L5(종합)·L6(평가)는 연습문제에서 다루는 구조입니다. 본문 학습 목표 수준이 L2~L4로 적절히 분포됩니다.

개선 여지: 목표 3번("기술할 수 있다")은 단순 L2보다는 "비트 필드를 분석하여 기능을 설명할 수 있다"로 L3 동사를 사용하면 더 정확합니다. 현재 7개 CSR의 비트 필드를 아는 것은 암기(L1)에 가까우나, 필드 간 관계(MIE-MPIE 연동)를 이해하면 L2~L3 수준입니다.

### 2. 18.1 → 18.5 학습 흐름의 논리성

**평가: 우수**

```
18.1 개념 도입 (특권 수준, CSR 정의, 주소 공간)
  ↓ 개념에서 레지스터 명세로
18.2 CSR 구조 (7개 레지스터 상세, csr_unit 구조 예고)
  ↓ 명세에서 명령어로
18.3 CSR 명령어 (6종 원자적 동작, 해저드 예고)
  ↓ 명령어에서 실습으로
18.4 실습 (3단계, 점진적 검증)
  ↓ 실습에서 정리로
18.5 요약 및 Ch19 예고
```

이 흐름은 개념→명세→명령어→실습→정리의 표준 교육 설계 패턴을 따릅니다. 각 절이 다음 절의 필요성을 자연스럽게 생성합니다.

특히 18.1절 끝의 "Ch17 timer_irq → mip.MTIP 연결" 언급은 18.2절 mip 학습 동기를 미리 심어주는 역할을 합니다. 학습 흐름 상 잘 배치된 복선입니다.

### 3. 인지 부하 분석: 7개 CSR → 3그룹 청킹의 효과성

**평가: 우수 (단, 그룹 C 명칭 개선 필요)**

**청킹의 효과**:
- 7개를 기억하는 것보다 3그룹(각 1, 3, 3개)으로 묶는 것은 Miller의 7±2 법칙 관점에서 명백히 우수합니다.
- 그룹 B의 시나리오 기억법("어디로? → 어디서? → 왜?")은 서술적 청크(narrative chunk)를 활용한 기억 강화 기법입니다. 특히 효과적입니다.

**개선 여지**:
- 그룹 C의 명칭 "인터럽트 제어 (2개) + 임시 저장 (1개)"는 이질적 요소를 억지로 묶어 오히려 분리된 기억 부담을 줍니다. "인터럽트 제어 및 보조 (3개)"로 수정하거나, mscratch를 그룹 B와 연결하여 "예외 처리 보조" 역할임을 먼저 설명하면 더 자연스럽습니다.
- 18.2절 도입부의 "당장 모두 이해되지 않아도 괜찮습니다" 안내 문구는 불안을 줄이는 데 효과적이지만, 어느 그룹을 먼저 외워야 하는지 우선순위가 없습니다. "그룹 B 3개를 먼저 이해하고 그룹 A를 연결하십시오"와 같은 학습 우선순위 안내가 있으면 더 좋습니다.

**인지 부하 분산 기법 사용 여부**:
- 비유(계기판, 119, ATM, 우편함) — 외재적 인지 부하 감소 ✓
- 표(비트 필드 정리) — 불필요한 인지 부하 제거 ✓
- aside 박스(팁, FAQ, 면접, 메타인지) — 본문 흐름 유지하면서 보충 ✓
- 전체 소스 코드 별도 섹션 — 완성 코드 불안 제거 ✓

### 4. 연습문제의 블룸 분류 커버리지

**평가: 우수**

| 번호 | 수준 | 내용 | 적합도 |
|------|------|------|--------|
| 1 | L1 기억 | 빈칸 채우기 (CSR 주소 비트 수, MIE 위치) | 적합 |
| 2 | L2 이해 | mtvec 핸들러 주소 계산 | 적합 |
| 3 | L3 적용 | CSR 명령어 시퀀스 실행 결과 계산 | 적합 |
| 4 | L4 분석 | 인터럽트 마스킹 조건 분석 | 적합 |
| 5 | L5 종합 | 성능 카운터 CSR 추가 설계 | 적합 |
| 6 | L6 평가 | CSR 해저드 해결 방안 비교 평가 | 적합 |

L1부터 L6까지 전 수준을 커버합니다. 연습문제 설계가 매우 우수합니다.

특히 연습문제 6번(L6 평가)은 "포워딩 vs NOP 삽입의 장단점 비교 + RISC-V 스펙 준수 관점에서 정당화"라는 다층적 평가를 요구합니다. 단순히 코드를 작성하는 것이 아니라 설계 결정을 평가해야 하므로, 실제 L6 수준에 해당합니다.

연습문제 5번(L5 종합)에서 mcycle의 자동 증가와 CSRRW 간 우선순위는 Ch18에서 직접 다루지 않은 내용으로 약간의 비계(scaffolding) 힌트가 있으면 좋겠습니다.

## 최종 의견

Chapter 18의 교육 설계는 전반적으로 탄탄합니다. 특권 수준 도입 → CSR 명세 → 명령어 → 실습 → 요약의 흐름이 논리적이고, 연습문제는 L1~L6 전 수준을 커버합니다. 청킹 전략(3그룹)과 시나리오 기억법은 효과적입니다.

필수 수정(연습문제 5번 비계 부족)과 권장 수정(instructor-tip 추가, 그룹 C 명칭)을 반영하면 ⭐⭐⭐⭐⭐ 달성이 가능합니다. 현재 상태로도 교육 설계 품질은 승인 기준(⭐⭐⭐ 이상)을 충분히 충족합니다.
