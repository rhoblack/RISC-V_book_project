### **17.1 APB 프로토콜: 주변 장치를 위한 심플한 버스**

#### 이해도: ⭐⭐⭐⭐ (매우 좋음)

**장점**
- 비유 3단계 적용: "고속도로 ↔ 동네 골목길" + 한계 명시(도로 폭 ≠ 프로토콜 파이프라인) ✅
- 신호 표 완벽: 10개 신호 모두 "신호명 / 방향 / 폭 / 설명" 형식 ✅
- Setup/Enable Phase 구분 명확 + PREADY=0 웨이트 상태 설명
- AHB vs APB 비교표: 6가지 항목으로 핵심 차이 명확화 ✅
- aside 박스 우수: 💡 실무팁 + ❓ FAQ + 🔍 메타인지 + 📌 강사팁 모두 배치 ✅

**막힘 포인트 분석**
- PSEL과 PENABLE의 차이: 17.2 FSM으로 명확히 설명됨 ✅

### **17.2 AHB-to-APB 브리지: 프로토콜 변환기**

#### 이해도: ⭐⭐⭐⭐ (매우 좋음)

**장점**
- 비유: "비자 발급 창구" → 추상적 프로토콜을 구체화 ✅
- FSM 구조 명확: 3상태(IDLE→SETUP→ACCESS) + hready_out 신호 역할 명확
- 파이프라인 래치: "AHB는 주소(T1) ≠ 데이터(T2)" → addr_reg 필요성 명확 ✅
- Back-to-Back Transfer 시나리오로 valid_reg 역할 설명 ✅
- 주소 디코더 표: addr[13:12]로 4개 슬레이브 1:1 매핑 ✅

**막힘 포인트 분석**
- valid_reg 역할: 충분히 설명됨 ✅

---

### **17.3 UART 컨트롤러: 직렬 통신의 심장**

#### 이해도: ⭐⭐⭐⭐ (매우 좋음)

**장점**
- UART 8N1 포맷: 8비트 + N + 1정지비트 = 10비트 명확 ✅
- 16× 오버샘플링: baud_div = 100MHz / (115200 × 16) ≈ 54 계산 예제 ✅
- TX/RX FSM 4단계 명확: 상태별 비트카운터 관리 + 샘플링 시점(bit_cnt=7, 15) ✅
- FIFO 원형 버퍼: "MSB만 다르면 Full" 명확 ✅
- 2단 동기화기: 메타안정성 방지 원리 명확 ✅
- W1C 인터럽트: 면접 포인트로 RMW vs W1C 비교 ✅

**막힘 포인트 분석**
- M3 FIFO 오버플로우: FAQ "루프백과 실제" 제공, "데이터 손실" 명시 권장 (선택)
- M4 baud_div 정확도: "54.235 → 54" 명시 권장 (선택)

---

### **17.4 GPIO 컨트롤러: 범용 입출력**

#### 이해도: ⭐⭐⭐⭐ (매우 좋음)

**장점**
- 방향 레지스터: DIR[i]=1(출력), DIR[i]=0(입력) 명확 ✅
- 2단 FF 동기화기: "메타안정성" + "항상 2단 이상" 실무 팁 ✅
- 상승 에지 감지: edge_detect = gpio_in_sync[i] && !gpio_in_prev[i] 이해도 높음
- Basys 3 매핑: LED 16개(출력), 스위치 16개(입력) ✅

---

### **17.5 APB 타이머: 주기적 신호 생성**

#### 이해도: ⭐⭐⭐ (좋음)

**장점**
- 프리스케일러: prescale_reg=99 → 100클럭마다 1tick 명확 ✅
- CMP 비교: count_reg == cmp_reg → count_match 신호 ✅
- AUTO_RELOAD: count 자동 리셋 → 주기적 인터럽트 ✅
- 1ms 타이머 설정: 두 가지 방법(PRESCALE=99,CMP=999 vs CMP=99,999) 예제 ✅
- Ch19 연결 안내: "timer_irq는 mip.MTIP와 연결" ✅

---

### **17.6 시스템 통합: 주변 장치 서브시스템 구성**

#### 이해도: ⭐⭐⭐⭐ (매우 좋음)

**장점**
- 비유: "중앙 우체국 + 여러 창구" → 통합 시스템 시각화 ✅
- PRDATA/PREADY MUX: psel 신호로 슬레이브 응답 선택 명확 ✅
- C 의사코드 드라이버: UART/GPIO/Timer 실무적 ✅
- 테스트벤치 품질: ahb_write/ahb_read 태스크 + 3개 테스트 + Pass/Fail 카운터 ✅
- 메타인지: baud_div=2일 때 'H' 송신 클럭 수 계산(320클럭) 검증 ✅
