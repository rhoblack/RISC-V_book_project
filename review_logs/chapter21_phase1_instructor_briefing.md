## 1. 강의 품질 기준: "강의실에 쓸 수 있는" 설명

### 원칙
**원고를 강의 스크립트로 그대로 읽을 수 있어야 함.**

### ✅ 강의에 적합한 설명 구조

```
1️⃣ 도입부 (호기심 문장)
   "오늘 배울 전력 소비는 두 가지로 나뉘는데,
    하나는 회로가 일할 때 생기는 전력,
    다른 하나는 아무것도 하지 않아도 생기는 전력입니다.
    어떤 게 더 클까요?"

2️⃣ 개념 설명 (직관적 비유)
   "동적 전력은 자동차 가속처럼 생각하면 됩니다.
    빨리 달릴수록(고주파수), 강하게 밟을수록(고전압) 휘발유가 더 빨리 소비됩니다."

3️⃣ 공식 제시 (차원 분석과 함께)
   "이것을 수식으로 쓰면 P = CV²f 입니다.
    전압(V)은 제곱으로 들어가므로 2배 올리면 전력은 4배가 됩니다!"

4️⃣ 손으로 계산하는 예시 (칠판 또는 슬라이드)
   "우리 설계가 100MHz에서 0.5V이고 0.8A를 쓴다면?
    P = 0.5² × 100M × ... 잠깐, 공식에 전류는 없지?
    맞습니다. 이 공식은 캐패시턴스만 알면 계산 가능합니다."
```

### ❌ 강의에 부적절한 설명 (피할 것)

```
❌ 공식부터 시작:
   "P_dynamic = CV²f + I_leak×V 공식을 봅시다"
   → 학생들 주의 산산조각, 흥미 한 번에 뚝

❌ 수학 기호만 나열:
   "C는 캐패시턴스, V는 전압, f는 주파수, I_leak은 누설전류..."
   → "이게 뭐하는 거지?" 혼란

❌ 추상적 정의:
   "정적 전력은 게이트 누설(gate leakage)과 부채널 누설(subthreshold leakage) 합계"
   → 대학원생도 "어?" 한다 (용어만 들었지 체감 안 됨)
```

### 개선 전략: 단계적 공개 (Gradual Reveal)

```
Step 1: 호기심 유발 (30초)
  "우리 설계를 1시간 방치하면 몇 W를 쓸까?"
  → 학생들: "잠깐, 아무것도 안 하는데도?"

Step 2: 현실 사진 또는 영상 (1분)
  [Vivado Power Report 스크린샷 또는 발열 카메라 사진]
  → "이게 실제 우리가 만든 칩의 발열입니다"

Step 3: 개념 "움직임/가만히" 프레임 (2분)
  "전력은 두 가지입니다:
   - 동적(Dynamic): 회로가 움직일 때(switching)
   - 정적(Static): 가만히 있어도 나는 전력"

Step 4: 비유로 깊이 더하기 (3분)
  각 비유마다 매핑과 한계 명시

Step 5: 공식 제시 + 손 계산 (5분)
  칠판에 P = CV²f 크게 그리고,
  "2배 전압 = 4배 전력" 손가락질

Step 6: 실제 Vivado 예시 (라이브 또는 녹화)
  학생들이 직접 본 설계로 전력 추정
  → "와, 내 코드가 얼마나 뜨거운지 알았다!"
```

## 2. 비유 설계 및 4가지 검증 기준

### 비유 설계 전략

각 비유마다 반드시 **4가지 검증**을 통과해야 함:
1. **기술 사실과 정확히 매핑 가능한가?**
2. **학생 눈높이(대학원 수준)에 맞는가?**
3. **한계를 명시했는가?**
4. **오해 유발 가능성은 없는가?**

### 예상 비유 매트릭스 (Ch21에 필수)

| 개념 | 비유 | 기술 사실 매핑 | 한계 | 대안 비유 |
|------|-----|----------|------|----------|
| **동적 전력** | 자동차 가속도 | V² = 강도, f = 빈도 | 진정한 전류흐름은 선형이지만 V²로 지수증가 | "춤추는 사람": 더 빨리 움직임 = 더 많은 에너지 소비 |
| **정적 전력** | 아이들링 자동차 | 움직이지 않아도 휘발유 소비 | 실제 누설은 온도/전압에 의존, 선형 아님 | "뜨거운 엔진": 주변과 온도차가 있으면 열 손실 |
| **PPA Trade-off** | 요리의 시간/맛/가격 | 시간↔품질↔비용 삼각 관계 | 요리는 보통 선형 아님, 개인화 필요 | "공부 시간/성적/건강": 학생들의 경험과 연결 |
| **열 관리** | 에어컨 필터 청결 | 청결↔바람↔소음 trade-off | 필터는 재사용 가능, FPGA는 불가; 필터 교체는 극단적 선택 | "냉각팬 RPM 조절": 항상 도는 게 정상, RPM은 동적 조절 가능 |
| **누설전류** | 손가락 사이로 흘러나오는 물 | 완전히 막을 수 없음, 자연현상 | 물은 중력, 누설은 "확산"(diffusion) — 메커니즘 다름 | "박새의 집 단열재": 완벽하지 않아서 천천히 열 손실 |
| **DVFS** (추가) | 자동차 순항 속도 자동 조절 | 느린 속도(저주파)→ 저전력 | 변속 오버헤드 있음, 모든 회로 가능한 건 아님 | "자전거 기어 변속": 오르막길(낮은 기어)에서 천천히 |

### 비유 검증 체크리스트 (각 비유마다)

```
✅ 매핑 정확도:
   자동차 가속 비유: V² = 액셀 압력, f = RPM
   ↓ 실제 전력: P = CV²f (정확히 매핑되지만...)
   ⚠️ 한계: 자동차는 토크 기반(보통 선형), 반도체는 V²—급격함

✅ 학생 눈높이:
   "자동차 가속"은 대학원생도 경험했음 (일상 비유 ✅)
   "반도체 물리"는 많은 학생이 모름 (전문지식 필요 ❌)
   → 따라서 자동차 → 전문 용어 순서가 맞음

✅ 한계 명시 (필수!):
   "이 비유는 여기까진 맞지만, 실제로는...
    - 자동차는 보통 선형이지만
    - 반도체는 V²이므로
    - 2배 전압 = 4배 전력 (자동차는 그렇지 않음)"

✅ 오해 방지:
   학생이 혼동할 수 있는 부분 명시
   예: "전력 = 전압 × 전류 맞나요?"
       → FAQ로 선제 해결
```

### 비유 한계 명시 예시 (원고에 포함할 문장)

```markdown
**💡 자동차 비유의 한계:**
이 비유는 "빠를수록 많이 쓴다"는 개념을 전달하는 데는 훌륭하지만,
한 가지 중요한 차이가 있습니다.
자동차의 연비는 속도에 거의 선형적이지만,
반도체의 동적 전력은 **전압의 제곱(V²)**에 비례하므로
훨씬 급격히 증가합니다.
따라서 "2배 속도 = 2배 휘발유"가 아니라
"2배 전압 = 4배 전력"이라는 점을 기억하세요.

**🔄 대안 비유:**
더 정확한 비유는 "춤을 추는 사람의 에너지 소비"입니다.
조용히 서 있으면 기초 대사량만 소비하지만,
춤을 빠르게 출수록 (높은 주파수),
강하게 움직일수록 (높은 전압),
심장이 빠르게 뛰고 (V²),
에너지가 매우 빠르게 소진됩니다.
이 비유가 "지수적 증가"를 더 잘 설명합니다.
```

#### 💡 Tip 2: V²f 공식 — "2배 전압의 마법"

```html
<aside class="tip">
💡 강의 중 팁: V²f 공식의 지수 효과
-----
칠판에 크게:
  P = C × V² × f

그리고 하나의 예시를 준비하세요:
  V = 0.5V → P = 0.25C×f
  V = 1.0V → P = 1.00C×f  (4배!)
  V = 1.5V → P = 2.25C×f  (9배!)

"전압을 2배 올릴 때마다 전력은 4배가 됩니다.
이것이 Dynamic Voltage Scaling(DVFS)이
중요한 이유입니다. 조금만 전압을 낮춰도
전력이 뚝 떨어집니다!"

학생들: 뭔가 신기한 거 배운 기분
</aside>
```

## 4. 면접 포인트 (기존 + 신규 5개)

### 면접 질문의 목적

**회사 인터뷰에서 나올 법한 질문들**로 학생들이 현업 감각을 키우도록 함.
각 질문마다:
- 기본 답변 (10초)
- 심화 답변 (30초)
- 반박 대비 (30초)

### Q1: "당신의 FPGA 설계가 얼마나 뜨거워질까?" (기본)

**배치**: 21.1절 이후 (개념 학습 후 즉시)

**기본 답변** (10초):
```
"우리 설계는 동적 전력과 정적 전력을 합쳐서 약 0.5W를 소비합니다.
Basys 3 보드는 냉각이 제한되어 있으므로
칩 온도가 상온보다 약 30-50°C 높을 것으로 예상됩니다."
```

**심화 답변** (30초):
```
"Vivado의 Power Estimator를 사용해서

### Q3: "Vivado 전력 추정을 믿습니까?" (도구 이해도)

**배치**: 21.4절 "Vivado 사용법" 이후

**기본 답변** (10초):
```
"네, 설계 단계에서는 믿습니다.

```

**심화 답변** (30초):
```
"Vivado의 전력 추정 정확도는 세 가지에 의존합니다:

1) **Activity Profile**: 우리가 예상한 활동 확률
   (실제로 모든 신호가 우리가 생각한 대로 변하지 않음)

2) **온도 추정**: Vivado는 25°C를 기본값으로 가정

3) **Post-Layout Effects**: 라우팅 후 기생 저항/용량
   (합성 단계에서는 정확히 모름)

따라서 정확도 향상을 위해서는:
- 실제 프로파일로 시뮬레이션 (toggle rate 측정)
- 온도 감지기 활용 (실시간 T 피드백)

- 설계 B: Vivado 추정 0.3W

비록 절대값에 ±10% 오차가 있더라도,

### Q4: "전력을 줄이려면?" (기법 이해도)

**배치**: 21.5절 "전력 최적화 기법" 이후

**기본 답변** (10초):
```
"세 가지 기법이 있습니다:
1) DVFS (주파수/전압 동적 조절)
2) Clock Gating (불필요한 회로에 클록 차단)
3) Power Gating (사용하지 않는 블록의 전원 차단)"
```

**심화 답변** (30초):
```
"각 기법의 효과:

1) **DVFS**: P = CV²f 이므로
   f를 50%로 낮추면 P = 0.5 (50% 절감)
   V를 90%로 낮추면 P = 0.81 (19% 절감)
   → V 감소의 효과가 더 큼!

2) **Clock Gating**: 예를 들어 CPU가 메모리 대기 중이면
   ALU의 클록을 막아서 동적 전력 0으로
   → 약 20-30% 전력 절감 (활용도에 따라)

3) **Power Gating**: CMOS 회로는 누설 전류 때문에
   사용하지 않는 블록의 전원을 완전히 끔
   → 누설 전력 근처 제거 (약 10-20% 절감)

우리 프로세서는 DVFS를 가장 쉽게 구현 가능합니다."
```

**반박 대비** (30초):
```
면접관: "모든 설계에서 DVFS가 효과적인가?"

학생 답변:
"아닙니다. DVFS 오버헤드를 고려해야 합니다:
- 주파수 변경 시 안정화 시간 (PLL settling)
- 전압 변경 시 인덕터 스윙 (Inductor current change)

따라서 1ms 이상 동일 주파수로 운영할 때만 효과적입니다.
매우 짧은 태스크(마이크로초 단위)에서는 오버헤드가 이득을 상쇄합니다.
이것이 **성능 예측 (workload characterization)**이 중요한 이유입니다."
```

### Q5: "전력 최적화의 우선순위는?" (시스템 이해)

**배치**: 21.6절 "성능 분석" 이후

**기본 답변** (10초):
```
"동적 전력 > 정적 전력입니다.
보통 동적이 정적의 10배 이상 크므로
동적 전력 최적화를 우선합니다."
```

**심화 답변** (30초):
```
"일반적인 프로세서 전력 분포:

  동적 전력: ~80% (회로 동작 시)
  정적 전력: ~20% (누설 전류)

하지만 이는 설계와 공정에 따라 다릅니다:

- **고주파 설계** (100MHz+): 동적 > 95%
  → DVFS와 Clock Gating에 집중

- **저전력 IoT** (10MHz): 동적 ≈ 정적 (60:40)
  → Power Gating도 중요

- **초저전압 설계** (0.3V): 정적 > 30%
  → Subthreshold 누설 최소화 필수

따라서 우선순위 결정은 **설계의 동작점**에 달려 있습니다.
우리 프로세서는 100MHz 설계이므로 동적 우선입니다."
```

**반박 대비** (30초):
```
면접관: "정적 전력이 온도에 의존한다면
        동작 중에 누설이 변하지 않나?"

학생 답변:
"정확한 관찰입니다! 온도 피드백이 중요합니다:
- T ↑ → I_leak ↑ → P_static ↑ → T ↑ (양의 피드백!)

이를 'thermal runaway'라고 합니다.
따라서:
1) Thermal sensor로 실시간 온도 모니터링
2) 온도 상승 시 DVFS로 주파수 낮춤
3) 극한 상황: 칩 잠금(throttling)

이것이 **열 관리(thermal management)**의 핵심입니다.
우리는 Vivado에서 추정하지만,
실제 제품은 이런 피드백 제어가 필수입니다."
```

## 6. 강사 팁 모음 (핵심 5개 + 추가 3개)

### 핵심 5개 (강의에서 필수)

1. **동적/정적 차이 — 30초 각인법**
   - 손 움직이고 가만히 있기 (신체 활용)
   - "움직임 = 에너지 소비" 프레임 고정

2. **V²f 공식 — "2배 전압의 마법"**
   - 칠판에 크게 P = CV²f
   - "2배 전압 = 4배 전력!" 손가락질
   - 예시: 0.5V → 1.0V → 1.5V (0.25 → 1.00 → 2.25)

3. **Vivado 신뢰성 — "도구는 완벽한가?"**
   - ±10% 오차는 정상
   - "절대값이 아니라 **상대값** 비교"
   - "이 도구 없으면 FPGA 산업이 없다"

4. **손 실습 성공 — "와! 내 설계도!"**
   - Vivado Power Report 라이브 데모 필수
   - 학생들이 직접 따라 하게 함
   - 자기효능감 증진이 목표

5. **면접 연결 — "왜 배워야 함?"**
   - 현업 5가지 질문 (Q1~Q5)
   - Qualcomm/NVIDIA 사례
   - "당신의 칩이 얼마나 뜨거울까?"

### 추가 3개 (선택, 시간 여유 시)

6. **온도 피드백의 위험성 — Thermal Runaway**
   - "T ↑ → I_leak ↑ → P ↑ → T ↑" (양의 피드백)
   - 현실 반도체는 이래서 냉각이 필수
   - 모바일 폰의 열 제한(thermal throttling) 사례

7. **Power Gating의 복잡성**
   - Power Domain 분할 (비용 high)
   - Leakage isolation 어려움
   - "모든 설계가 Power Gating을 할 수는 없다"

8. **대안: 연구 주제로 제시**
   - "전력 측정의 정확도를 높이려면?"
   - "실시간 열 관리 알고리즘?"
   - 학생들의 대학원 연구 주제로 영감 제공

### 교육전문강사의 관점에서 Ch21의 위치

**Ch21은 "Part 8의 영웅적 마무리"입니다.**

- **Ch19**: 예외/인터럽트 (복잡성 최고)
- **Ch20**: 합성과 타이밍 (추상성 최고)

Ch21에서 **"아, 이게 왜 중요한지 이제 안다"**는 깨달음을 얻습니다.

1. **도입**: 호기심 (발열 사진, "얼마나 뜨거울까?")

3. **비유**: 설득 (자동차, 춤, 요리)
